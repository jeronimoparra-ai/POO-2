Caso de Estudio

Este proyecto implementa un sistema completo de gestión de biblioteca universitaria usando los principios fundamentales de la Programación Orientada a Objetos en Java.

El sistema permite registrar libros y usuarios, realizar y devolver préstamos, buscar por título o autor, generar recibos automáticos y consultar el historial global de préstamos.

  • Registrar libros y usuarios en el sistema
  • Prestar libros con verificación de disponibilidad y límite de 3 por usuario
  • Devolver libros y actualizar inventario automáticamente
  • Buscar libros por título o por autor
  • Generar recibo de cada préstamo realizado
  • Consultar el registro global de todos los préstamos
🔒

Encapsulamiento

Todos los atributos son private. Solo accesibles mediante getters y setters públicos.

🌳

Herencia

Clases Libro y Usuario son superclases extendidas por tipos especializados.

🔄

Polimorfismo

Método mostrarInfoLibro() se sobreescribe con comportamiento distinto en cada subclase.

public class Libro {
  private String titulo;
  private String autor;
  private String genero;
  private boolean disponibilidad;
  private int unidades;

  public boolean prestar() {
    if (this.unidades > 0) {
      this.unidades--;
      actualizarEstado();
      return true;
    }
    return false;
  }

  public void devolver() {
    this.unidades++;
    actualizarEstado();
  }

  public void actualizarEstado() {
    this.disponibilidad =
      this.unidades > 0;
  }
}

public class Usuario {
  private static final int
    LIMITE_PRESTAMOS = 3;
  private String nombre;
  private String apellido;
  private int id;
  private List<Libro> librosPrestados;

  public boolean verificarLimite() {
    return librosPrestados.size()
      < LIMITE_PRESTAMOS;
  }

  public boolean prestarLibro(
      Libro libro) {
    if (verificarLimite() &&
        libro.isDisponibilidad()) {
      librosPrestados.add(libro);
      libro.prestar();
      return true;
    }
    return false;
  }
}

public class SistemaBiblioteca {
  private List<Libro> catalogo;
  private List<Usuario>
    usuariosRegistrados;
  private List<Recibo>
    registroDePrestamos;

  public List<Libro> buscarPorTitulo(
      String titulo) {
    List<Libro> resultados =
      new ArrayList<>();
    for (Libro l : catalogo) {
      if (l.getTitulo().toLowerCase()
          .contains(titulo.toLowerCase()))
        resultados.add(l);
    }
    return resultados;
  }

  public void realizarPrestamo(
      Usuario u, Libro l) {
    if (u.prestarLibro(l)) {
      Recibo r = new Recibo(l, u);
      registroDePrestamos.add(r);
      r.generarRecibo();
    }
  }
}
